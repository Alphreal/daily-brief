For learning — how this recreation works

Steal this structure for any website.

Open this file in a text editor. Search LEARN #1…#5. Every effect below is 5–15 lines.

1. Shell
<header> <main> <footer>
One H1. Sticky header. Max-width 1440px. This alone makes you look pro.
2. Layout
grid / flex
Hero = grid 2-col → 1-col on phone. Bento = 3-col with one card spanning 2 rows.
3. Motion
transform + opacity
Hover lift, carousel fade, scroll reveal. Never animate width. 150–300ms.
4. JS in 4 verbs
go() / filter / toggle / observe
Carousel, live search, pricing, reveal. View source bottom <script>.
5. Feel the vibe
Adobe vibe = big type + saturated gradients + round 16px cards + generous whitespace. Copy those 4 and any clone feels “Adobe”.
