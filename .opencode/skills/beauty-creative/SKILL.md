# Beauty Creative (contextual, research-backed, flexible)

Complements `website-build` (structure) + `diagram-generate` (pictures). This owns beauty judgment + creative loop.

## Beauty is not fixed: Universal form × Context fit (Redies 2015)

Two modes: (1) perceptual bottom-up universal (form triggers beauty mechanism), (2) cognitive top-down contextual (content, intent, presentation, culture). Score = form × fit. High form + wrong context still fails.

Context lens first (Jacobsen: person/situation/content; Darda ingroup/context):
- Theme: goal/genre (brief scan vs textbook study vs festive) — sets complexity + tone weights.
- Situation: device/place/time/urgency (phone 390px rush vs desktop study; museum vs online vs print changes judgment — Gerger).
- Human: who (age/culture/expertise/access needs/taste; VN first-years vs teachers). Early perception universal, late judgment culture-specific (2025 Chinese-German study). State assumed viewer or ask.

## What humans find beautiful (keep all 5)

1. Symmetry/balance — universal health cue, easiest win (Rhodes 1998; Bertamini). Mirror left/right, align to grid.
2. Proportion — classical Canon/Golden-ratio-like thirds, not exact math worship (Polykleitos; Vitruvius; GR preferred for people/art, symmetry beats GR for abstract).
3. Fluency — pleasure of easy processing (Reber fluency): clear hierarchy, moderate complexity, curved over sharp, high figure-ground contrast 4.5:1.
4. Naturalness — youth/health cues, clean texture, honest materials; no clutter that signals decay.
5. Learned match — must fit viewer's internal model (culture/exposure). Test with 1 real viewer; familiarity raises liking.

If 2+ fail, it reads as not-beautiful even if one is perfect.

## Creative mindset (improve / ask / promote / flex)

- Improve when needed: after each draft run 1-line beauty audit (which of 5 fails?) then fix one only. Never redesign all at once.
- Ask for help: opt-in, never auto. Offer 3 aids (FlexMind 2025): (a) alternative schemas, (b) risk/tradeoff note, (c) steer my draft. Wait for pick.
- Promote initial idea: use "How Might We…" + pin promising option early (design thinking: observe → reframe promotion-frame → imagine → fail-faster test). Grow idea before judging.
- Flexible choices: divergent 3 options (fluency/originality/flexibility) → convergent pick 1 with reason. Dual-pathway: flexible-shift categories first, persist-deep second (Nijstad). Avoid LLM homogenization: force 1 weird + 1 minimal option.

## Flow (Context → See → Vary → Pick → Improve)

1. Context: state Theme/Situation/Human in 1 line each (or ask max 2 questions if missing). This weights the 5 checks below.
2. See: score 5 beauty checks PASS/FAIL *for that context* with file:line or screenshot ref.
3. Vary: produce 3 directions (safe / bold / minimal) *tuned to same context*. Ask which to promote.
4. Pick: user picks 1; state why in 1 line (which context need it serves).
5. Improve: fix top-1 FAIL only, re-score, then DONE → skill-keeper if new rule.

## Don'ts

- No beauty-by-assertion ("make it prettier" without 5-check + context). No 10-option dump (paradox of choice kills creativity). No rigid linear gate that blocks backtracking. No one-style-fits-all (same layout cannot serve rush-scan + deep-study + festive without retune).
